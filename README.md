# FORMA OBJECTS — интернет-магазин мебели и предметов интерьера

Учебный проект курсовой работы: «Разработка клиентской части интернет-магазина мебели и предметов интерьера».

## Возможности
- Главная страница, категории и адаптивная навигация.
- Каталог с поиском, фильтрацией по категориям и цене, сортировкой и пагинацией.
- Карточка товара и добавление в корзину.
- Корзина с изменением количества и удалением позиций.
- Оформление заказа с проверкой контактных данных, адреса, доставки и оплаты.
- Регистрация, авторизация, профиль и история заказов.
- Административная зона: добавление/редактирование пользовательских товаров, просмотр заказов и изменение их статусов.
- Адаптивная верстка для телефонов, планшетов и компьютеров.
- DummyJSON REST API: /products, /auth/login, /users/add, /carts, /carts/add.

## Технологии
React 18, React Router 6, Vite 5, CSS, DummyJSON REST API, localStorage.

## Важное примечание
Это клиентская учебная демонстрация. DummyJSON имитирует API и не сохраняет изменения на сервере. Корзина, профиль, созданные заказы и изменения каталога хранятся в localStorage браузера. Реальная оплата, защищённая серверная авторизация и серверная база заказов требуют отдельной backend-части.
