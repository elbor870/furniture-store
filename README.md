# FORMA HOME — интернет-магазин мебели

Учебный проект курсовой работы Борисенко Елисея Константиновича, группа 454.

## Запуск локально

```bash
npm install
npm run dev
```

## Публикация на GitHub Pages

Проект собирается Vite в каталог `dist`. Workflow `.github/workflows/pages.yml` автоматически собирает и публикует сайт после push в ветку `main`.

1. Откройте Settings → Pages в репозитории.
2. В разделе Build and deployment выберите Source: **GitHub Actions**.
3. Откройте Actions и дождитесь успешного workflow Deploy FORMA HOME to GitHub Pages.

Сайт будет доступен по адресу https://elbor870.github.io/furniture-store/.

## Реализовано в клиентской части

- Главная страница, категории, каталог, поиск, сортировка и карточки товаров.
- Корзина с сохранением в localStorage.
- Оформление демонстрационного заказа.
- Учебный вход в профиль и история заказов в localStorage.
- Панель управления товарами и статусами заказов; изменения сохраняются в браузере.
- Адаптивная вёрстка.

## Важные ограничения

GitHub Pages — статический хостинг. Данные localStorage доступны только в конкретном браузере и не синхронизируются между пользователями или устройствами. Вход здесь демонстрационный: он не проверяет пароль на сервере и не обеспечивает защиту административной панели. Оплата не подключена. Для настоящей авторизации, защищённой админки, общей базы заказов и оплаты потребуется backend и база данных.

DummyJSON используется как внешний демонстрационный API для проверки сетевого доступа; его операции записи не являются постоянным хранилищем магазина.
